## 01 / ABOUT

I'm **Vinuga Kisath**, a cybersecurity and network technology student from Sri Lanka.

Currently pursuing a Higher Diploma in Network Technology & Cyber Security at ICBT, through the Cardiff Metropolitan University pathway.

I'm interested in understanding the technology behind modern infrastructure — from network protocols and operating systems to application security and the tools used to defend them.

I enjoy experimenting, building small projects, exploring security environments, and documenting what I learn.

My approach is simple:

> Don't just learn how technology works. Understand why it works, where it breaks, and how to make it better.
